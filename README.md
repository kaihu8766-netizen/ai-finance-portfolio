## 质量控制是怎么做的

财务数据对准确性零容忍，而 AI 生成的代码与测算容易"看起来对"。所以我把金融机构的 **经办 — 复核 — 审批（Maker-Checker）** 机制搬到数据建模里：

1. **经办**：按 Actual/360、季末月 20 日结息、年度重定价等规则，由 AI 生成计算代码；
2. **复核**：换另一个模型独立验算现金流与折现结果，交叉比对边界异常；
3. **裁决**：本人核验勾稽关系与数据口径后放行。

这套逻辑与「前后台制衡、四眼原则（Four-Eyes）」一致：经办与复核分离，分歧沉淀为规则，对外交付的测算报表要求逻辑闭环、可追溯。
