# 双 Agent 协作契约 v1.0（2026-10-23 用户拍板，v7.5 起执行）

## 背景
AI 司库新产品（v7.4）为 A 类改动但未走开工前对齐，复盘确认协作方式需制度化。
用户拍板采纳 DSH 提案 7 条 + 追加第 8 条，本文件为唯一权威契约。

## 条款

1. **A/B 分级**：A 类（新作品/定位/用户可见叙事/口径数字/删减/公开措辞/≥2 文件）开工前走对齐单；B 类直接做。
2. **对齐单内容**：需求理解 / 范围 / 验收标准 / 主要风险 / 做法 + 面试官视角栏 + 未决定项清单。
3. **采纳后动手（fail-closed）**：对齐单经采纳（分歧项用户拍板、附收益/影响评估）落档后才动手；未采纳动手 = 违规。
4. **复核门禁不变**：三件套 + RV 编号 + 主 Agent 复测盖章；A 类复核对照对齐单查跑偏。
5. **B 类开口子**：触口径数字或公开文案（哪怕一行）→ 动手前一行知会主 Agent；其余直接做。
6. **成本控制**：对齐单 ≤1 屏、最多一轮往返；分歧项等待用户不受此限。
7. **记录**：对齐单落 trace/03-会议与日志/DeepSeek评审/ 或 RV 档案，可追溯。
8. **超时兜底**：A 类对齐请求 1 轮未回或超 24h 未响应 → DSH 记录「未对齐」并暂停动手，由用户裁决是否直接开工；不得以等对价为名无限挂起，也不得未经采纳擅自开工。

## A 类回溯案例（首个，不作追责）

- **v7.4 AI 司库新产品 + 双旗舰首页**：按新契约属 A 类（新作品 + 定位 + 用户可见叙事 + 多文件），实际走「DSH 先做 → 主 Agent 事后复核」，未开工前对齐。
- 复盘结论：产品定位/功能取舍/写给谁看均在事后才评审，方向风险高（若定位偏离需整体返工）。
- 落地动作：本契约 v7.5 起执行；主 Agent 承担开工前拦截职责。

## 执行提示
- 主 Agent 职责：评审/门禁/盖章/发布/开工前拦截/面试官视角补全。
- DSH 职责：写代码/A 类对齐单起草/三件套自检/降级路径自测。
- 用户职责：分歧项拍板（拍板选项附收益/影响评估，先行后拍）。
