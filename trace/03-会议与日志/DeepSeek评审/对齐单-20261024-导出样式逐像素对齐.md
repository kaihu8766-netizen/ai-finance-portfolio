## 三、范围
- **A. 样式全量对齐（核心）**：把模板 11 sheet 的列宽 / 行高 / 合并 / 字体（字体名/字号/加粗/斜体/下划线/颜色）/ 填充 / 边框（四边样式+颜色）/ 对齐（水平/垂直/换行/缩进）/ 数字格式，逐格应用到导出。
  - 实现：`tools/v714_gen.py` 从模板生成 `demo/ai-treasury-copilot/export-style.js`（紧凑样式表，约 10KB）；导出前 `applyTemplateStyles()` 统一套用（列宽/行高/合并/样式）。
  - 顺序：先写单元格样式（**跳过合并从属格**，避免 ExcelJS 从属格样式回写主格）→ 再合并 → 再列宽/行高。
- **B. 汇总页 KPI 说明行补齐**：A6/D6/G6/J6/M6 五条说明，数值随数据刷新（笔数/本金亿元/LPR/到期年份），不写死。
- **C. 动态行数（底部对齐）**：导出排程行数 > 模板时，表头块（≤18 行）原样、排程行沿用模板排程行样式、合计行沿用模板合计行样式（避免多出的一行被合计样式污染）。
- **D. 版本与统计**：footer v7.14、时间线新增 v7.14、kb.versions / KB 版本话术追加；统计回填 **84 轮复核 / 65 条批准基线**（统计区、防御清单、KB 话术；REVIEW_STAMP 严格「✅ 已批准」行 = 65 已实测）。

## 五、边界与风险（诚实说明）
1. **字体可用性**：模板字体为 Noto Sans CJK SC / Microsoft YaHei / Segoe UI。Windows Excel 无 Noto 时会回退，属模板自身的字体选择，本单保持与模板一致（不改字体名）。
2. **数据驱动行数**：LM04–LN09 导出排程比模板多 1 行（模板为静态样本），扩展行按底部对齐规则套样式；模板行号与导出行号在该区域不一一对应，校验按映射口径。
3. **静态值不复制**：模板中导出未计算的静态单元格（除 r6 说明行外）不搬值，只搬样式，避免过期样本数据污染动态导出。
4. **导出依赖**：新增 `demo/ai-treasury-copilot/export-style.js`（同源静态资源），加载失败时导出仍可用（仅样式退回原实现，`applyTemplateStyles` 返回 false）。
5. 本轮为 A 类：对齐单 → 用户拍板 → 执行（已完成实现与自测）→ 复核 AI RV + 豆包盖章 → CI 双绿 → 线上验证。
