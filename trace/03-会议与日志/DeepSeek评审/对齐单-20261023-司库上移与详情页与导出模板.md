# 对齐单 · 司库上移 / page-04 详情页 / 导出换模板

## 一、需求原文（用户三句话，显式拍板）
1) 新的作品可以放在 LPR 上面
2) 新的作品缺少一个和 LPR 一样的介绍页面
3) 作品中的一键导出用我这个表格（《某大型新能源整车制造企业_集团贷款还款总表(动态穿透版).xlsx》）

## 二、模板核验（主 Agent 用 openpyxl 实测，与 DSH 分析一致）
- 11 sheets：集团贷款汇总总表 + LN01~LN09 单笔附表 + 参数配置与敏感性测算
- 9 笔 LN2026-001~009（工行 7000 / 建行 6000 / 中行 5500 / 农行 5000 / 交行 4500 / 招行 4000 / 中信 3500 / 兴业 3000 / 浦发 3000 万）= 合计 **415,000,000 = 4.15 亿**；WAVG 3.31%
- 全部 12 个月、到期还本；首年 LPR 3.10%、次年 3.00%（重定价），利差 15bps，首年执行 3.25% / 次年 3.15%
- LN01 单笔表：合同要素 + 年度重定价 + 按季排程（期次/计息起止/实际天数/在贷本金/基准LPR/浮动点差/执行年利率/日基准利率/当期应付利息/本期还本/现金流出）
- 参数表：PAR_LPR_1Y=3.10%、PAR_DAY_COUNT=360（Actual/360）、PAR_SETTLE_CYCLE=按季结息（每季末月20日结息21日扣款）、PAR_CORP_TAX=15%、PAR_DEBT_CAP=5 亿 + 6 档 LPR 情景敏感性

## 三、拍板依据（显式选择缺失披露）
- 用户显式拍板 = 上述三句原始指令
- U 项 = 用户选择框两次返回空（界面问题，未再给出显式选项）→ 按主 Agent 推荐组合执行：**U1-A（9 笔替换 4 笔）/ U2-A（ExcelJS）/ U3-A（iframe 内嵌）/ U4-B（效果图不入仓）/ U5 必须（引擎补按季结息+年度重定价）**
- **披露**：U1-U5 显式选择缺失，依据「用户原始指令 + 推荐组合」执行；若用户后续否决任一 U 项，v7.6 相应调整
