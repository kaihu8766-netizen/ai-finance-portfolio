1. 集团现金流压力测试与流动性测算原型
资金司库 · 极端场景测算
测算效率提升
0.5 天 ➔ 30 分钟
蒙特卡洛模拟路径
10,000 条
核心参数覆盖
汇率 / 利率 / 流贷到期

业务痛点来源：在集团资金管理中，传统依赖 Excel 编制的现金流预测在面对突发多币种汇率剧烈波动、集中到期还贷叠加销售回款延期等极端情景时，手工情景调参耗时耗力，无法给出量化置信区间。

数字化解决方案：构建基于 Python 的蒙特卡洛压力测试原型，输入期初头寸、到期债务矩阵及汇率波动方差，一键跑通 10,000 条模拟路径，输出 95% 与 99% 置信度下的最低安全头寸边界。

2. 发票合规预审与三单匹配规则工作台 (invoice-precheck)
业财融合 · 自动化风控
票面硬伤前置拦截
90%+
初审周转效率
单张 < 0.5 秒
规则引擎覆盖
税号 / 尾差 / 三单勾稽

业务痛点来源：企业日常报销与采购付款中，财务初审大量时间被消耗在基础票面硬伤审核（税号错误、开票超期、敏感类目）以及订单-入库单-发票的手工比对上，错审漏审风险高。

数字化解决方案：基于 Python 开发规则引擎原型，解析发票元数据，前置拦截虚假开票、价税分离勾稽尾差，并与模拟采购订单及发货验收单自动执行三单对碰（3-Way Matching）。
